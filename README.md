## 📌 Sobre a apresentação

Este repositório contém a apresentação da **Sprint Review 1** do projeto **SIMAD**, desenvolvida para demonstrar o planejamento, os resultados e os aprendizados da primeira Sprint do semestre.

Nesta etapa, o foco principal da equipe foi a migração do sistema para **Laravel**, buscando preservar o banco de dados, as informações cadastradas e as funcionalidades existentes.

## 🌧️ Sobre o SIMAD

O **SIMAD — Sistema Integrado de Monitoramento e Alerta de Desastres** é um projeto de extensão desenvolvido por estudantes do curso de Análise e Desenvolvimento de Sistemas do IFSP.

O sistema tem como objetivo apoiar a Defesa Civil de Campo Limpo Paulista/SP no registro, gerenciamento, monitoramento e acompanhamento de ocorrências relacionadas a desastres e situações de risco.
